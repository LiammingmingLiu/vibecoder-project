# 游搭 YOODA · Demo 打包

一句话找到今晚的游戏搭子。本包为黑客松现场演示用的可交互原型。

---

## 怎么跑

双击 `游搭_网页版.html`，用 Chrome / Edge / Safari 打开即可。**无需安装、无需服务器、断网可跑。**

> ⚠️ `游搭_网页版.html` 和 `assets/` 必须放在同一层目录，移动时请一起移动。
> 图片加载失败时会静默回落到内置的 SVG 占位图，演示不会开天窗。

## 演示走位（约 60 秒）

1. **Onboarding** — 填昵称 + 一句话自我介绍，或点右侧标签芯片自动写入
   （示例：`主玩三角洲行动，打突击位，打法激进，声音低音炮，晚上在线`）
2. 系统解析成**搭子名片** → 点「就是我」
3. **主界面**输入需求，或点下面的示例胶囊
4. 「开始匹配」→ 标签逐条弹入 → 雷达扫描 → 卡片 3D 翻牌
5. 结果页看「为什么是 TA」→ 点「开聊」→ 对方回复并给出 KOOK 房号
6. 底部「未来：绑定 Steam…」→ 打开愿景弹层（Roadmap 三卡）

**背景交互**：鼠标悬停任意游戏卡片 → 该排立即暂停、卡片放大，并弹出「这是什么游戏」的提示。

**重置状态**：浏览器控制台执行 `localStorage.clear()` 后刷新。

## 匹配逻辑（已验证的用例）

| 输入 | 结果 |
|---|---|
| 随便来个搭子 | 随缘匹配，每次结果不同 |
| 想打瓦 | 无畏契约池 |
| 今晚打三角洲，我打突击，找个支援位的女生 | 三班倒的支援（识别位置互补） |
| 找个稳健的女生周末一起玩方舟，最好甜妹音 | 驯龙高手（四条件全中） |
| 打战地6，我工程兵，找个突击兵 | 冲锋号响了（长词优先，"突击兵" 不被拆成 "突击"） |
| 今晚吃鸡，找个不骂人的老哥 | PUBG 池，识别出找男生 |

规则：**游戏与性别是硬过滤**，其余（声音 / 风格 / 时段 / 位置互补）加权排序。
匹配不到完全符合的人时**永不返回空态**，降级为最接近的人选并诚实说明。
「换一个」同一请求最多 3 次，每次排除已出现的人。

## 换正式授权图

拿到授权后，直接用同名文件覆盖 `assets/` 下对应的 jpg 即可，**代码一行不用改**。
建议 900×500 以上、jpg 或 webp、单张控制在 200KB 内。

三个位置会同时换掉：背景卡片流、结果卡顶部横幅、聊天窗顶栏。

品牌图：`mark.png`（顶栏方形标记）、`logo.png`（完整字标，备用）。

## 技术说明

纯前端单文件，无后端、无构建、无框架。

- 动效：GSAP 3.12（CDN）。加载失败自动降级为 CSS 动画，不影响流程
- 状态：`localStorage`，刷新不丢
- 解析与匹配：本地规则引擎，**离线可跑**

正式版按 SPEC 走 Next.js + Supabase + DeepSeek 三段管线（解析 → 预筛 → 重排）。
接入时把 `parse()` 和 `rank()` 换成 `/api/match` 的 SSE 调用，UI 层无需改动。
